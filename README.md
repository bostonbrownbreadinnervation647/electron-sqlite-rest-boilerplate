## 📦 What this is

electron-sqlite-rest-boilerplate is a desktop app template for Windows, macOS, and Linux. It uses Electron, SQLite, and a REST API layer. That means the app keeps data on your computer and works well when you need fast access to local records.

This project fits apps that store lots of data, work offline, or need a simple local backend inside the desktop app.

## 🔐 Data storage

The app stores data in SQLite, which keeps records in a local database file on your computer. This helps the app start fast and stay stable even without internet access.

Local storage is a good match for:

- Forms
- Tables
- Saved settings
- Searchable records
- Small to medium business data

## 🧩 Project structure

The template uses a clear app layout that helps keep the code organized:

- **Desktop layer:** Electron handles the app shell and windows
- **API layer:** Express serves local REST routes
- **Data layer:** SQLite stores records in a local database
- **UI layer:** React shows the screens and forms
- **Build layer:** Vite handles fast development and builds

This structure keeps the app easier to extend for future work.
